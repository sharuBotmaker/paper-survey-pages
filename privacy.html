プライバシーポリシー

paper-survey は運営者本人だけが使う個人用ツールです。

  • Google ユーザーデータへのアクセスは https://www.googleapis.com/auth/drive.file スコープに限られます。このツールが作成したファイルとフォルダだけを作成・更新します。
  • 取得した認証情報は利用者本人の実行環境にのみ保存され、第三者に提供・販売・共有しません。
  • Google ユーザーデータを広告や機械学習モデルの学習に使用しません。
  • アクセスは https://myaccount.google.com/permissions からいつでも取り消せます。

Google API から受け取った情報の使用は、限定使用要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。
